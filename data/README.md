# /data — Modell (Single Source of Truth)

`model.schema.json` definiert das normalisierte, backend-unabhängige Modell:
**hubs**, **devices** (+commands), **scenarios** (Szenario = Activity, mit **Geräte-Roster**).

Echte Daten gehören nach `/data/local/` (gitignored). Hier liegt nur ein sanitisiertes Beispiel.
